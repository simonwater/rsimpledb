# rsimpledb
 This project is a rust version of [SimpleDB](https://www.comp.nus.edu.sg/~tankl/cs3223/project/setup.htm) originally written in Java by Edward Sciore. SimpleDB is a basic RDBMS described by the book [Database Design and Implementation](https://www.amazon.com/dp/3030338355/?mr_donotredirect) by Edward Sciore.
